| 34 | The declared legacy-writer policy decides, and marker text alone never blocks | [ADR-034](decisions/034-legacy-writer-policy-is-a-runtime-decision.md) | `legacy_writers` becomes a runtime authority input, and historical L9 metadata text stops being classified as an active competing writer. |
| 35 | A file that cannot carry its own metadata falls back instead of aborting | [ADR-035](decisions/035-unsupported-inline-carrier-falls-back.md) | Unsupported frontmatter routes to the central manifest with a diagnostic, source bytes are preserved, and only an unsatisfiable explicit inline authorization holds. |
| 36 | Canonical local-source and archive observation is read-only and staging-based | [ADR-036](decisions/036-read-only-local-source-acquisition.md) | An arbitrary file, folder, drive tree or ZIP is observed without Git and without mutation; sibling `.l9extracted` materialization is superseded for observation, archive members become hash-identified virtual artifacts with `DERIVED_FROM` ancestry, and preflight plus a two-sided resource budget replace the `unzip` subprocess as the security boundary. |
| 37 | Corpus intelligence is artifact-scoped evidence plus two separately-classed duplicate analyses | [ADR-037](decisions/037-corpus-intelligence-artifact-scope-and-duplicate-topology.md) | Assertions attach to the artifact that made them and the packet stops rewriting subjects; work state is read only from explicit declarations; exact duplicates stay facts and near-duplicates stay candidates, with `DUPLICATE_OF` rendered in the corpus index rather than forced into the consumer's edge vocabulary. |
| 38 | A corpus spans several roots, reuses content-addressed work, and emits readiness evidence without ranking it | [ADR-038](decisions/038-multi-root-corpus-incremental-cache-and-readiness-evidence.md) | A root is identified by its declared key rather than its mount point, so a remount changes nothing and a diff stays possible; every derived layer is keyed on content and rules, hashing is never skipped and `mtime` never decides identity; duplicate, near-duplicate, topic and project analysis crosses root boundaries; and readiness is emitted as counts and citations with priority, score and percent-complete refused by name. |
| 39 | A measured run over a mixed read-only corpus is a first-class artifact | [ADR-039](decisions/039-real-corpus-qualification-report.md) | Property suites prove the invariants and are written to be insensitive to corpus content; a third qualification measures a deliberately mixed two-root corpus and emits `l9.corpus-qualification-report/v1` — scanned bytes, second-run hit ratio, decoder coverage, duplicate and candidate counts, and what could not be read split by why. The report and the run that passed are one execution, no absolute path or ranking appears in it, and non-mutation is proven by a digest over content and mode rather than by a read-only flag root would falsify. |
| 40 | Semantic candidates are multi-signal evidence, and the reasoning queue is a routing decision | [ADR-040](decisions/040-semantic-candidate-discovery-and-reasoning-handoff.md) | Corroboration counts by evidence family, so three lexical metrics over one document's vocabulary count once; topic, project and consolidation candidates make three different claims and none of them is a fact; exact duplication stays a fact and is not evidence of a shared project; reasoning eligibility is mostly a refusal, with exact duplicates and embedding-only candidates routed to NONE and every routing carrying a reason; embeddings are off by default, remote needs a second opt-in, and raw vectors never leave the cache. Scope amended with owner authorization to text formats: no binary document decoder exists, so the binary-locator prerequisite and cross-format qualification were dropped rather than silently deferred. |
| 41 | A corpus has two identities, a hash says how it was obtained, and a missing drive stays visible | [ADR-041](decisions/041-corpus-source-identity-verification-class-and-partial-corpora.md) | Source identity excludes every analysis profile and analysis identity binds them all, so changing a model or a threshold no longer reports that the disks were rewritten; each root emits its own Repository Model Packet under `roots/<root>/bundle/` and its packet id participates in the source snapshot; cached interpretations carry no subject and are rebound per root, closing a defect where one root's artifacts absorbed another's documents; `--incremental` may carry a prior hash forward and the snapshot is then `cached_unchanged_assumption`, never `fully_verified`, with `--verify-content` restoring one; `--allow-partial-roots` records a missing drive in the snapshot and labels the corpus partial rather than dropping it; readiness metrics are grouped with their denominators and separate three kinds of not-knowing. |
| 42 | Documents are decoded, work is bounded, and evidence is bound to what it describes | [ADR-042](decisions/042-binary-document-decoding-generational-publication-and-bounded-candidate-work.md) | Closes ADR-040's text-only scope amendment: seven decoders for PDF, OOXML, notebooks, CSV and HTML with no new runtime dependency, each block citing its own format's coordinate and no format without lines given a line number. Decoded text enters lexical analysis on format rather than extension, so a `.docx` reaches the same candidates a `.md` does, and `document-signals.json` reports per format whether it did. Diff counts are computed from a snapshot analysis manifest or reported `null` with a reason, never zero. Worker budgets are implemented or removed and a retired flag is refused by name. Topic candidates run at ten thousand documents under an exact rarest-first prefix bound — 47,428,930 exhaustive pairs, 9,733 evaluated — held to an exhaustive reference at six thresholds. Outputs publish into `generations/<id>/` behind one atomic `CURRENT.json` switch, cache and session writes fsync file then parent, roots declare whether their identity was declared or inferred, a real archive is scanned only when an operator names one, the topology harness proves it wrote nothing into the consumer checkout, and the validation report is bound to a digest of the tree it ran over. |

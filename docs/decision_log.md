| # | Decision | ADR | Rationale |
|---|---|---|---|

| 17 | Omit layer, SKILL.md protect, and Cursor-native skills mode | [ADR-017](decisions/017-omit-skill-protect-skills-mode.md) | Inventory/pipeline must not corrupt agent skills; skills mode improves Cursor `description` under materiality. |

| 25 | Central metadata is one deterministic canonical JSONL index | [ADR-025](decisions/025-deterministic-central-metadata-index.md) | Non-hard-skip records are path-sorted, machine-independent, idempotent, and isolated under .l9. |
| 26 | Check and apply consume one carrier-aware plan | [ADR-026](decisions/026-unified-carrier-aware-operation-dispatch.md) | Policy, index materialization, and authorized inline targets cannot diverge between planning and mutation. |
| 27 | Apply commits its complete carrier set transactionally | [ADR-027](decisions/027-whole-run-transactional-apply.md) | Same-directory staging, durable journaling, post-commit validation, and reverse rollback prevent mixed repository state. |
| 28 | Inline YAML updates patch managed fields without reserializing user headers | [ADR-028](decisions/028-byte-preserving-frontmatter-safety.md) | Exact fences, byte-preserved bodies, and fail-closed complex YAML prevent collateral header damage. |
| 29 | Release 4.0.0 by immutable commit before consumer migration | [ADR-029](decisions/029-v4-release-and-consumer-migration.md) | GitHub commit consumption is sufficient; npm publication and consumer rollout retain separate fail-closed gates. |
| 30 | Repository Model Packet egress is produced from inventory evidence and proven against the bound topology consumer | [ADR-030](decisions/030-repository-model-packet-egress.md) | Contract accuracy is proven by the real consumer, not asserted, and no runtime dependency on topology is created. |
| 31 | A shared manifest filename is not package-manager evidence | [ADR-031](decisions/031-shared-manifest-filenames-are-not-package-manager-evidence.md) | `pyproject.toml` cannot identify Poetry, uv, PDM or setuptools by name; lockfiles can, and the gap is emitted as a diagnostic instead of a guess. |
| 32 | Repository semantics come from a separate deterministic interpretation pass | [ADR-032](decisions/032-deterministic-repository-interpretation-seam.md) | Inventory keeps answering what exists; a versioned offline pass answers what files declare, every assertion cites an exact hashed span, and competing claims are preserved rather than resolved. |
| 33 | Skills mode requires repository authority and commits transactionally | [ADR-033](decisions/033-skills-mode-repository-authority.md) | Realizes INV-018: skills now fails closed without authority and routes protected SKILL.md writes through the governed compare-and-swap transaction instead of a direct write. |
| 34 | The declared legacy-writer policy decides, and marker text alone never blocks | [ADR-034](decisions/034-legacy-writer-policy-is-a-runtime-decision.md) | `legacy_writers` becomes a runtime authority input, and historical L9 metadata text stops being classified as an active competing writer. |
| 35 | A file that cannot carry its own metadata falls back instead of aborting | [ADR-035](decisions/035-unsupported-inline-carrier-falls-back.md) | Unsupported frontmatter routes to the central manifest with a diagnostic, source bytes are preserved, and only an unsatisfiable explicit inline authorization holds. |
| 36 | Canonical local-source and archive observation is read-only and staging-based | [ADR-036](decisions/036-read-only-local-source-acquisition.md) | An arbitrary file, folder, drive tree or ZIP is observed without Git and without mutation; sibling `.l9extracted` materialization is superseded for observation, archive members become hash-identified virtual artifacts with `DERIVED_FROM` ancestry, and preflight plus a two-sided resource budget replace the `unzip` subprocess as the security boundary. |
| 37 | Evidence is scoped to the artifact that declared it, and the corpus layer stops at evidence | [ADR-037](decisions/037-artifact-scoped-evidence-and-corpus-intelligence.md) | Assertions may name a repository or a single artifact, including a virtual archive member; deterministic extractors read declared work state without inferring it; exact duplicates are facts and near-duplicates are candidates that never claim shared topic or propose consolidation; the corpus index is a projection that adds no truth. |
